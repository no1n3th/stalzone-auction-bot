# Changelog

## [3.2.0] — 2026-10-03 (UI: переосмысление интерфейса)

### Добавлено
- Настройки пользователя (`/settings`): звук уведомлений (вкл/выкл, громкость, выбор
  типов событий, порог профита), тёмная/светлая тема. Сохраняются в БД (user_settings,
  миграция 007). Звук играет только когда вкладка не активна (Web Audio, без файлов).
- Лента событий: выдвижная панель справа (drawer) при клике на предмет — мини-график,
  тренд за период, ссылка «Открыть на рынке». Анимация появления новых событий.
- Рынок: сортировка ликвиды → неликвиды (без подписей категорий), треугольники тренда
  (▲ зелёный рост / ▼ красный падение / ■ жёлтый без изменений), спарклайн-мини-график
  в каждой строке, периоды графика (24 ч / 3 дн / нед / мес / год), прогноз на 3 дня
  отдельным блоком из трёх чисел с трендом.
- Индикатор «Минимум/средняя/максимум» за выбранный период над графиком.

### Изменено
- Админка переписана «для людей»: понятные названия («Сканирование аукциона» вместо
  scanner_enabled) и описания под каждым переключателем. Статистика простыми словами.
- Сделки: убран ROI (оставлены Профит, Баланс, Прогноз баланса).
- Удалены вкладки «Обзор» и «Рынок» как отдельные сущности в навигации главной —
  их содержимое переехало в детализацию ленты и drawer.
- Пользовательские настройки звука применяются глобально (на всех страницах).

  больше не реэнкьюит строку каждый цикл поверх бэкоффа; `_send_batch` не
  дублирует ретраи в DLQ для outbox-payload; мультивебхук ретраит только

- P3-2: `AlertManager` без alerting-вебхука не создаёт очередь.
- P2: удаление пользователя — нельзя удалить себя/последнего админа (409),
  сделки удаляемого чистятся, сессии отзываются; глобальный лимит входа
  по IP (`ip:`-ключ, D9); границы схем сделок (`item_id` ≤ 32, `note` ≤ 500,
  `amount` ≤ 1 000 000, запрет inf/nan).

  `history_sync_enabled`, `meta_monitor_enabled`, `season_monitor_enabled`,
  `charts_enabled`, `discord_enabled` (D10); тест `test_admin_flags_runtime.py`.
- P0-1: иконки из поля `icon` листинга (`ru/icons/<подтип>/`), embed без
  thumbnail при отсутствии иконки (D11).
- P1-7: спред стабилизации только по продажам после инвалидации
  (`window_spread_pct(..., since=...)`, D12).
- `utils/public_guard.py` — лимит 30 зап/мин/IP + кэш 45 с на публичных
  `/api/market|daily-prices|forecast` (D8).
- `settings.metrics_token` (защита `/metrics`) и `settings.forwarded_allow_ips`
  (uvicorn `proxy_headers` — throttles видят реальный IP за прокси).
- `.env.example`; тесты `test_public_guard.py`, `test_outbox_backoff.py`.

### Изменено
- CI: `pip-audit` и `npm audit --audit-level=high` без `|| true`; добавлены
  `npm run lint` и `npm test` во фронтенд-гейты.
- requirements: убран Jinja2 (embed собираются словарём с P0-5); dev-зависимости
  + freezegun, respx.

## [3.1.0] — 2026-09-30 (подготовка к ЗБТ)

### Исправлено (P0)
- P0-1: справочник предметов парсит реальный плоский `listing.json`; пустой парс
  не затирает кэш; имена артефактов — fallback; Dockerfile не запекает пустой кэш.
- P0-2: outbox (гарантированная доставка Discord): `await` enqueue, персист
  синхронно до очереди, флаг реплея `persist=False`, фильтр возраста 120 с,
  heartbeat sweep-воркера (`/health/ready` больше не всегда 503), prune в
  retention, миграция `005_outbox_fix` (NOT NULL-drift + `next_attempt_at`).
- P0-3: карантин 4xx-предметов — scheduler внедряется в сканер конструктором.
- P0-4: `parse_api_time` (ISO/epoch), все окна по `coalesce(sold_at, created_at)`,
  пагинация истории `limit=200/offset`, watermark `>=`, миграция `006` (backfill + индекс).
- P0-5: embed собирается словарём (без Jinja), thumbnail только с валидным URL,
  цвет редкости применяется, единый формат денег, лимиты Discord.

### Исправлено (P1)
- P1-1: dip-buy — алерт один раз на вход, refire при ухудшении ≥5 п.п. или 6 ч.
- P1-2: средняя для +10…+14 считается от базы +15 (как SampleSizeFilter).
- P1-3: `mark_sent` после отправки; изоляция исключений на уровне лота.
- P1-4: истёкшие лоты не формируют «стену» рынка.
- P1-5: чужой маркер цены в кэше графиков.
- P1-6: сезонные события тегируются годом старта; end закрывает все открытые start-ключи.
- P1-7: флаг `invalid:*` снимается по TTL при отсутствии продаж.
- P1-8: гонка первого админа (lock до commit); порядок проверок регистрации.
- P1-9: сделки — 404/409 разведены, закрытые не редактируются, summary без тихого лимита.
- P1-10: статистика админки из БД; `GET /api/admin/audit`.
- P1-12: `CircuitOpenError`; валидация JSON-тела API.
- P1-13: `log_json=false` даёт читаемые логи; `Literal`-режимы; warn о битом JSON вебхуков.
- P1-14: `Retry-After` при HTML-429; корректный `unfinished_tasks`; окно ожидания индекса 10 с.

### Безопасность и эксплуатация (P2)
- PBKDF2 600 000 итераций + прозрачный перехеш при входе.
- Заголовки безопасности на всех ответах; `/metrics` — опциональный токен.
- Единая версия в `config/version.py`; `GET /api/meta` (version/fee_pct/registration_open).
- compose: `${DB_PASSWORD:?set DB_PASSWORD}` (без дефолтного пароля).
